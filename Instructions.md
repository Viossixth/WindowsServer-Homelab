**Instructions**

Steps to follow 

* Spin up a Windows Server VM (Hyper-V or VMware, whichever you have on hand)
* Promote it to a domain controller, create a couple of OUs, users, and groups
* Build a GPO or two (something visible like a mapped drive or printer deployment)
* Configure a DHCP scope with a reservation, and DNS records
* Join a second VM (client) to the domain
* Set up a file share with NTFS permissions
* Document it on GitHub with screenshots — same format as your existing cloud lab writeups
