# WindowsServer-Homelab

This is a 8 Phase Homelab where I used an Azure Virtual Machine running WindowsServer2022 Datacenter to familiarize myself with Server Manager and its features.

I did the following tasks :

- Creating the Azure infrastructure to host the VM running WindowsServer.
- Setting up Active Directory Domain Services and adding new features.
- Creating a forest (lab.local) and joining a new computer.
- Configuring DHCP, DNS, Shared Network Folder, RBAC Permissions, RDP Permission
- Creating Group Policy Objects, Group Policy, Organizational Units, Users
- Troubleshooting any problems and ensuring the created resources or network works as intended.
