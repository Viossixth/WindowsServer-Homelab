**Phase8**

In the last phase i had to create a shared folder. Unlike the solution to resolve the GP wallpaper issues, this shared folder has permissions and access is granularly controlled. The folders are similar with different applications.

The solutions is to create a folder on the network instead of on a drive (Similar to the Group Policy wallpaper solution). The catch this time is that i went to advanced sharing settings, shared the folder to everyone on the Domain but gave permissions to the selected users (Principle of least privilege). This created a shared network folder.
