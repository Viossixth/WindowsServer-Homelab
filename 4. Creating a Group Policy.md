**Phase 4**

Phase 4 entails creating a Group Policy. I decided that i want all users to have the same default wallpaper. I chose to set the Group Policy to apply to a wallpaper so that i can easily see if the GP is effective.

To create a Group Policy first you have to create a Group Policy Object via the Group Policy Manager. I created a new GPO called NewHire and applied it to all the users created in Phase 3.
I then downloaded the wallpaper and noted the root path. Using Group Policy Management Editor I configured the wallpaper Group Policy.
